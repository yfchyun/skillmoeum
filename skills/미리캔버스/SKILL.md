# 미리캔버스

글·안내서(PDF·한글·워드·붙여넣은 글)를 받아 **미리캔버스 규격의 홍보 이미지**를 만들고, 미리캔버스에서 마무리하도록 안내한다.

## 0. 먼저 알 것
- 미리캔버스(miricanvas.com)는 **공식 API·MCP가 없다.** 그래서 이 스킬은 그림을 **직접 만들어(PNG)** 건네고, 사람은 미리캔버스에 **업로드해서** 글자·사진을 바꾸거나 공유한다.
- 계정 로그인·업로드·결제는 **사람이 직접** 한다. 대신 하지 않는다.
- 캔바 연결(Canva MCP)이 있으면 캔바 시안을 함께 만들어 비교하게 해도 된다.

## 1. 규격 (미리캔버스 템플릿 크기와 같음)
| 쓰임 | 크기(px) |
|---|---|
| 인스타 피드·카드뉴스(세로) | 1080 × 1350 |
| 인스타 정사각 | 1080 × 1080 |
| 인스타·페이스북 스토리 | 1080 × 1920 |
| 페이스북 게시물·링크 | 1200 × 630 |
| 유튜브 썸네일 | 1280 × 720 |
| A4 포스터(인쇄) | 2480 × 3508 (300dpi) |

## 2. 만드는 순서
1. **내용 뽑기**: 안내서에서 제목·한 줄 메시지·일정·장소·비용·정원·강사·신청/문의를 뽑는다. 정해지지 않은 것(장소 미정, 신청 방법 미정 등)은 지어내지 말고 비워 둔 뒤 마지막에 알려 준다.
2. **콘셉트 정하기**: 안내서 디자인을 그대로 베끼지 않는다. 사진형·채팅형·타이포형 등 **다른 느낌**을 고른다. 본보기 `본보기/채팅형_포스터.html`(?v=feed|story|fb), `본보기/채팅형_카드뉴스.html`(?v=2~6)을 참고한다.
3. **사진**: 써도 되는 사진만 쓴다(퍼블릭 도메인·CC0·CC BY). CC BY는 그림 구석에 작게 «사진: 작가, 라이선스» 표기. 교회·단체가 준 사진은 그대로 써도 된다.
4. **HTML 쓰기**: 글꼴은 Pretendard(본문) + Noto Serif KR(제목) 등 무료 글꼴. 한 파일에 `?v=` 로 여러 크기를 담는다. 글자는 크게, 한 장에 메시지 하나.
5. **그리기**: `bash 도구/그리기.sh 파일.html?v=feed 1080 1350 결과.png`
6. **눈으로 확인**: 만든 PNG를 반드시 열어 본다 — 글자 잘림·겹침·빈 공간·사진 출처 위치. 고친 뒤 다시 그린다.
7. **건네기**: 바탕화면에 `<행사이름>_홍보물/` 폴더로 모으고, 여러 장이면 zip으로도 묶는다.

## 3. 미리캔버스에서 마무리하는 법 (사용자에게 그대로 안내)
1. miricanvas.com 로그인 → **디자인 만들기** → 위 표의 크기와 같은 템플릿(예: «인스타그램 피드») 또는 **직접 입력**으로 같은 크기 선택.
2. 왼쪽 **업로드** → 만든 PNG를 끌어다 놓기 → 캔버스에 꽉 차게 배치.
3. 바꿀 글자(신청 링크·QR·문의처)는 **텍스트** 도구로 그 위에 덧쓰기. QR은 **요소 → QR코드**.
4. **다운로드** → PNG(웹용) 또는 PDF 인쇄용(A4 포스터).
5. 카드뉴스는 페이지를 추가해 1→n 순서로 올리고, 다운로드할 때 «모든 페이지».

## 4. 하지 않는 것
- 미리캔버스·인스타·페이스북에 대신 로그인하거나 올리기.
- 남의 사진·로고·유료 폰트를 허락 없이 쓰기.
- 안내서에 없는 날짜·금액·연락처를 지어내기.
